# TODO list Python + Flask

It's a very simple TODO list project made with Python + Flask for task management.

## Installation

Just clone the project to your local machine.

```bash
git clone
```

## Usage

```python
# create the database with
from app import db

# then
db.create_all()

# start the program
py app.py
```
